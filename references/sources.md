# Bộ UI/UX tham khảo

Giấy phép và ngày cập nhật kiểm bằng GitHub ngày 26/11/2026. Dung lượng, tốc độ và trợ năng chưa đo.

## Dùng được

| Nguồn | Giấy phép | Lấy gì |
|---|---|---|
| [Astryx](https://github.com/meta/astryx) | MIT | Luật component, layout, cách đặt token |
| [shadcn/ui](https://github.com/shadcn-ui/ui) | MIT | Nền đang dùng. [Attachment](https://ui.shadcn.com/docs/components/radix/attachment), [Item](https://ui.shadcn.com/docs/components/radix/item), [Typeset](https://ui.shadcn.com/docs/typeset) |
| [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines) | MIT | Danh sách kiểm giao diện: [command.md](https://github.com/vercel-labs/web-interface-guidelines/blob/HEAD/command.md) |
| [ui-skills](https://github.com/ibelick/ui-skills) | MIT | Luật cho agent: [baseline-ui](https://github.com/ibelick/ui-skills/blob/HEAD/skills/baseline-ui/SKILL.md) |
| [make-interfaces-feel-better](https://github.com/jakubkrehel/make-interfaces-feel-better) | MIT | Luật trau chuốt chi tiết |
| [HyperUI](https://github.com/markmead/hyperui) | MIT | [Ô số liệu](https://hyperui.dev/components/application/stats), [trạng thái trống](https://hyperui.dev/components/application/empty-states). HTML thuần |
| [Magic UI](https://github.com/magicuidesign/magicui) | MIT | [Marquee](https://github.com/magicuidesign/magicui/blob/HEAD/apps/www/registry/magicui/marquee.tsx), phải tự thêm giảm chuyển động |
| [Kibo UI](https://github.com/shadcnblocks/kibo) | MIT | [Dải ngày](https://github.com/shadcnblocks/kibo/blob/HEAD/packages/mini-calendar/index.tsx), [thẻ chọn](https://github.com/shadcnblocks/kibo/blob/HEAD/packages/choicebox/index.tsx). Chữ tiếng Anh viết cứng. Lần cập nhật cuối 05/2026 |
| [coss ui](https://github.com/cosscom/ui) | MIT | [Ô mã OTP](https://github.com/cosscom/ui/blob/HEAD/apps/ui/registry/default/ui/otp-field.tsx), [ô số](https://github.com/cosscom/ui/blob/HEAD/apps/ui/registry/default/ui/number-field.tsx). Nền Base UI, chỉ lấy chỗ shadcn thiếu |
